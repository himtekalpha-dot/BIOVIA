BIOVIA — Halaman Jelajahi Materi

FILE:
- jelajahi.html : halaman katalog materi
- jelajahi.css  : gaya tambahan halaman Jelajahi Materi
- jelajahi.js   : pencarian, filter, modal ringkasan, navigasi responsif

CARA MEMASANG:
1. Ekstrak ZIP.
2. Salin ketiga file ke folder yang sama dengan dashboard BIOVIA.
3. Pastikan file dashboard utama bernama index.html dan file style.css dashboard tetap berada di folder yang sama.
4. Buka index.html, lalu klik menu "Jelajahi Materi".
5. Jika ingin membuka langsung, buka jelajahi.html.

FITUR:
- 4 kategori: Biologi Manusia, Hewan, Tumbuhan, Sel & Mikroorganisme.
- 12 kartu materi awal.
- Filter kategori dan pencarian materi.
- Modal ringkasan saat tombol Pelajari diklik.
- Layout responsif untuk desktop, tablet, dan ponsel.

CATATAN:
Ini masih prototipe front-end. Tombol "Mulai Pelajari" menampilkan pemberitahuan karena halaman detail materi, model 3D, akun siswa, dan database belum dihubungkan.
